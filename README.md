##  Description

A Machine Learning project that predicts whether a loan application will be **Approved** or **Rejected** based on applicant information such as income, education, employment status, credit history, and loan amount. The model helps automate the loan approval process and supports data-driven lending decisions.

# 🚀 Features

* Data preprocessing and cleaning
* Handling missing values and categorical variables
* Exploratory Data Analysis (EDA)
* Feature engineering and encoding
* Loan approval prediction using Machine Learning
* Model serialization using Pickle
* Interactive web application built with Streamlit
* Real-time loan approval predictions

# 📊 Dataset

* Uses a Loan Approval Dataset from Kaggle
* Contains applicant demographic, financial, and credit-related information
* Target variable indicates whether a loan application is approved or rejected
